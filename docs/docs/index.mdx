# `rglk.js`

Simple library for development roguelike games, designed for training/educational purposes.
Inspired by [rot.js](http://ondras.github.io/rot.js/hp/).

### Installation

```bash
# via Node.js and NPM
npm add rglk

# via Deno
deno add npm:rglk

# via Bun
bun add rglk
```
